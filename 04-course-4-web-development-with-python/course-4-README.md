# Course 4: Web Development with Python

**Duration:** 23 hours

## What This Course Covers

A comprehensive introduction to building dynamic web applications using Python and the Flask framework. Covers handling user interactions, working with databases, developing APIs, and deploying secure and reliable web applications — including HTML/CSS/JavaScript fundamentals, building web apps with Flask, working with databases via SQL and ORMs like Flask-SQLAlchemy, developing RESTful APIs, deploying to cloud platforms, and implementing security measures.

## Skills Gained

Flask (Web Framework), RESTful API, Object-Relational Mapping, Selenium, HTML and CSS, Web Applications, Secure Coding, Full-Stack Web Development, Web Development, Databases, Application Security, Front-End Web Development, JavaScript Frameworks, Cloud Deployment, Back-End Web Development, Collaboration

## Tools/Software

Python, Flask, HTML, CSS, JavaScript, SQL, Flask-SQLAlchemy, Vue.js
