# Course 2: Data Analysis and Visualization with Python


## What This Course Covers

Delves into data analysis with Python using libraries like pandas and Matplotlib to manipulate, analyze, and visualize data, extracting valuable insights and communicating findings effectively. Covers data cleaning, transformation, and manipulation using pandas; creating various types of visualizations using Matplotlib; understanding the fundamentals of generative AI and its applications in data analysis; and implementing basic machine learning models for data analysis.

## Skills Gained

Data Cleansing, Data Quality, Matplotlib, Data Manipulation, Machine Learning, Pandas, Data Analysis, Exploratory Data Analysis, Generative AI, Data Literacy, Data Ethics, Scientific Visualization, Plotly, Interactive Data Visualization, Data Visualization, Model Evaluation, Data Presentation

## Tools/Software

Python, Jupyter Notebook, pandas, Matplotlib, Plotly, Scikit-learn
