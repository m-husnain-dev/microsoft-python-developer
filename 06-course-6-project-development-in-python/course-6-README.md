# Course 6: Project Development in Python

**Duration:** 20 hours

## What This Course Covers

Focuses on managing and executing Python projects effectively in a collaborative environment — project management principles, DevOps practices, Agile methodologies, client communication, and career-building strategies. Covers applying project management principles to Python development, using DevOps tools like Docker and Kubernetes, implementing Agile principles for iterative development, interpreting client requirements, building and training basic chatbots, and creating a portfolio/resume for the job search.

## Skills Gained

Project Management, Requirements Elicitation, Agile Software Development, DevOps, Kubernetes, Requirements Analysis, Communication, Application Deployment, Docker, Stakeholder Communications, Stakeholder Management, Collaboration, Business Requirements, Containerization, System Monitoring

## Tools/Software

Docker, Kubernetes, Prometheus, Grafana, Jira, ChatterBot, spaCy
