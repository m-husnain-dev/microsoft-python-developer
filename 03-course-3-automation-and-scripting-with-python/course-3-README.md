# Course 3: Automation and Scripting with Python


## What This Course Covers

Focuses on automating tasks and improving efficiency using Python. Covers writing scripts for file manipulation, data extraction, web scraping, and interacting with APIs — automating file operations and data extraction, web scraping using BeautifulSoup and Scrapy, interacting with REST APIs using the requests library, integrating with third-party services like email and cloud storage, scheduling automated tasks using cron jobs and Task Scheduler, and optimizing/scaling automation scripts.

## Skills Gained

Automation, Scripting, Web Scraping, API (Application Programming Interface), RESTful API, Git, GitHub, File Management, Command-Line Interface, Unit Testing, File I/O, Cloud API, Shell Scripting, Email Automation, Test Script Development

## Tools/Software

Python, os, shutil, glob, BeautifulSoup, Scrapy, requests, smtplib, imaplib, cron, Task Scheduler
