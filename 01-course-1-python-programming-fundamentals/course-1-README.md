# Course 1: Python Programming Fundamentals


## What This Course Covers

Build foundational Python programs using core syntax, control flow, lists, and essential programming concepts. Create reusable Python code using functions, scope, classes, modules, and common data structures. Apply error handling and debugging techniques to identify and resolve issues in Python programs. Test Python applications, use version control practices, and apply skills in a hands-on capstone project.

## Skills Gained

Python Programming, Data Structures, Unit Testing, Debugging, Code Reusability, Git (Version Control), Algorithms, Jupyter, Version Control, GitHub, Programming Principles, Scripting

## Tools/Software

Python, Jupyter Notebook, Git, GitHub
